# KiCad Power Sheet Implementation Spec

Target: `hardware/kicad/power.kicad_sch`  
Status: DESIGNING — V1 5 V architecture

This supersedes the early 5–28 V/buck concept. V1 is powered by an external tightly regulated 5.0 V high-current supply.

## Sheet interfaces

Inputs:
- `+5V_IN`
- `GND`

Outputs:
- `+5V_SYS`
- `+5V_SERVO_A`
- `+5V_SERVO_B`
- `+5V_SERVO_C`
- `+5V_RADXA`

`+3V3_LOGIC` is supplied by Radxa and is never generated by this sheet.

## A. Main 5 V input and reverse protection

```text
XT60 J1 -> F1 20 A -> LM74700-Q1 + BSC009NE2LS5I -> +5V_SYS
```

Frozen controller: `LM74700QDBVRQ1`.
DBV pin map: 1 VCAP, 2 GND, 3 EN, 4 CATHODE, 5 GATE, 6 ANODE.

External MOSFET: `BSC009NE2LS5I`, SuperSO8/PG-TDSON-8. Pins 1–3 SOURCE, pin 4 GATE, pins 5–8 DRAIN.

Critical topology:
- F1_OUT -> U1 ANODE and Q1 SOURCE.
- Q1 DRAIN -> +5V_SYS and U1 CATHODE.
- U1 GATE -> Q1 GATE.
- C_VCAP = 100 nF from VCAP to ANODE.
- C_U1_IN >= 22 nF ANODE-to-GND, local.
- C_U1_OUT >= 100 nF CATHODE/+5V_SYS-to-GND, local.
- U1 EN has a defined enabled state and bring-up test access.

ANODE/CATHODE sensing uses Kelvin-style connections and must not share a narrow sense segment with the 15–20 A current corridor.

## B. +5V_SYS distribution

`+5V_SYS` is a distribution plane/pour, not a routed narrow trace. It feeds three servo groups and the Radxa eFuse branch.

Initial central bulk:
- 470 uF / 16 V low ESR
- 100 uF / 16 V
- 1 uF ceramic
- 100 nF ceramic

Keep a TVS footprint but do not treat a conventional SMBJ5.0A as sufficient over-voltage protection for XL330. Clamp/OV behavior remains a bench-validation item.

## C. Servo branches

Three nominal groups, five XL330-M288-T servos each:

```text
+5V_SYS -> configurable high-current link -> +5V_SERVO_A
+5V_SYS -> configurable high-current link -> +5V_SERVO_B
+5V_SYS -> configurable high-current link -> +5V_SERVO_C
```

Each branch starts with:
- 470 uF / 16 V low ESR
- 100 uF / 16 V
- 1 uF X7R
- 100 nF X7R

Theoretical branch stall current is about 7.35 A. Connectors, links, pours and vias must therefore be designed for transient current above normal walking load.

## D. Radxa protected branch

```text
+5V_SYS -> TPS259470ARPWR -> +5V_RADXA -> Radxa header pins 2 and 4
```

Frozen first-pass values:
- `R_ILM = 825 ohm 1%` (~4.05 A typical target)
- `C_DVDT = 3.9 nF` (~9.75 ms nominal 0–5 V ramp target)
- OVLO divider: `374 k / 100 k` (~5.69 V nominal)
- EN/UVLO pull-up: `390 k` to +5V_SYS, with test access

Host output bank:
- 470 uF low ESR
- 2 x 22 uF X7R
- 1 uF
- 100 nF

The reverse-current blocking function is mandatory for prototype USB-C/HAT coexistence testing. Do not replace it with a 0-ohm bypass before validation.

## E. Radxa header power pins

- pin 2 -> +5V_RADXA
- pin 4 -> +5V_RADXA
- pins 6,9,14,20,25,30,34,39 -> GND
- pins 1,17 are host 3.3 V outputs and must not be driven here

## F. Test points

Required:
- TP_5V_IN
- TP_FUSED
- TP_5V_SYS
- TP_SERVO_A
- TP_SERVO_B
- TP_SERVO_C
- TP_5V_RADXA
- TP_HOST_EN
- TP_HOST_STATUS/FLT
- at least two convenient GND scope pads

## G. PCB current rules

Target stack: 4 layer, 2 oz outer copper.

- Main input/fuse/MOSFET/distribution corridor uses large polygons on outer layers in parallel.
- Target >=15 mm equivalent copper width for short 20 A-class main segments where geometry permits.
- Dense stitching vias at J1, F1, Q1 and branch split points.
- No neck-down through thermal-relief spokes on high-current pads; use deliberate solid/high-current connections where manufacturable.
- Servo return current must not pass through Radxa/audio ground-return corridor.
- Keep LM74700 sense routing quiet even though the power copper is large.
- TPS25947 input/output capacitors must be close to the device.

## H. Net classes

`MAIN_5V_HIGH_CURRENT`: +5V_IN, F1_OUT, +5V_SYS.

`SERVO_5V`: +5V_SERVO_A, +5V_SERVO_B, +5V_SERVO_C.

`HOST_5V`: +5V_RADXA.

`POWER_CONTROL`: LM74700 gate/sense support, TPS25947 EN/OVLO/ILM/DVDT/status.

## I. Placement order

1. Radxa mechanical outline/header and keepouts.
2. XT60 input.
3. Main fuse.
4. LM74700 + external MOSFET + local capacitors.
5. +5V_SYS split region.
6. Three servo branch connectors and branch bulk capacitors.
7. TPS25947 and host output bank close to header pins 2/4.
8. Test points.
9. Only then route low-current signals.
